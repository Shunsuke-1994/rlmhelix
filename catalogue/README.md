# RLM-Fam catalogue

The RLM-Fam catalogue and the per-window results of the genome scan will be deposited on Zenodo (DOI to be added;
public upon publication of the paper). This directory holds no data files: it documents the files of the deposit and
how to regenerate them with this repository.

| File | Content | Regenerated by |
|---|---|---|
| `rlmfam_candidates.tsv` | One row per candidate (15,821), the Catalogue sheet of Supplementary Table S4 | `rlmhelix catalogue build -o` |
| `families.tsv` | One row per provisional family (14,037), the Families sheet of Supplementary Table S4 | `rlmhelix catalogue build --families` |
| `alignments/<core_id>.sto` | Final alignment of each candidate (final55): the human core and its homologues in up to 55 species (median 34), including paralogous loci, aligned with the covariance model; Stockholm with the human structure as `#=GC SS_cons` and the human columns as `#=GC RF`; the human row is named by the `core_id` | `rlmhelix select expand`, as `select/expand/candidates/<core_id>/final55.sto` |
| `cms/<core_id>.cm` | Infernal 1.1.5 covariance model built from that alignment | `rlmhelix select expand`, as `select/expand/candidates/<core_id>/final55.cm` |
| `scan_windows.parquet` | All 7,869,821 scan windows (200 nt, step 100, both strands): coordinates, strand, region type, RLMHelix score, calibrated P value and Benjamini–Hochberg q value; about 280 MB | `rlmhelix scan prepare`, `scan score`, `scan fdr`; `scan fdr` writes `eligible_windows.parquet` (all columns, with sequences and lfdr; about 1.0 GB), of which this file keeps the columns listed |

Coordinates are hg38 (GRCh38). Columns ending in `_0based` and `core_end` follow the BED convention (0-based start,
end exclusive); `locus_hg38` and the loci of `families.tsv` are 1-based inclusive, as in genome browsers.

## Candidate table (`rlmfam_candidates.tsv`)

Sorted by tier, then lfdr. Boolean columns are `True`/`False`; empty cells mean not available.

**Identity, locus and structure**

| Column | Definition |
|---|---|
| `rlmfam_id` | RLM-Fam family ID, as used in the text (RLMFam and five digits; a provisional family, the connected component of reciprocal CM scores; 14,037 families) |
| `core_id` | ID of the structural core in the scan (the query of the homology search and the name of the alignment and CM files) |
| `family_size` | Number of candidates in the family |
| `evidence_tier` | A, statistical and structural support; B, one of the two; C, neither. Tiers order candidates for validation and guarantee neither function nor a false discovery rate |
| `tier_evidence` | Evidence behind the tier (statistics, icSHAPE, covariation, or none) |
| `chrom` | Chromosome |
| `strand` | Strand |
| `core_start_0based` | Core start (0-based) |
| `core_end` | Core end (exclusive) |
| `locus_hg38` | Core coordinates in genome-browser format (1-based inclusive) |
| `core_length_nt` | Core length (nt) |
| `n_base_pairs` | Base pairs in the predicted core structure |
| `n_stems` | Stems of at least four consecutive pairs in the core structure |
| `core_score` | Total RLMHelix weight of the retained base pairs of the core |
| `core_sequence` | Human core RNA sequence (source strand) |
| `core_structure` | Predicted core structure (dot-bracket; RLMHelix DP decoding of the scan window) |

**Scan statistics**

| Column | Definition |
|---|---|
| `scan_p` | Smallest calibrated P value among same-strand scan windows overlapping the core (peak P); 0 = below the resolution of the calibration |
| `max_window_z` | Largest z = −Φ⁻¹(P) among overlapping windows |
| `lfdr` | Smallest local false discovery rate (Efron empirical null) among overlapping windows; 0 where P underflows. Written in full precision by `catalogue build` (four significant digits in Supplementary Table S4) |
| `min_window_bh_q` | Smallest nominal Benjamini–Hochberg q among overlapping windows |
| `bh_window` | An overlapping window has a nominal BH q ≤ 0.05 |
| `statistical_support` | `bh_window` or lfdr ≤ 0.2 (4,379 candidates), from the unrounded lfdr; use this column rather than thresholding a rounded `lfdr` |
| `n_top1pct_windows` | Overlapping same-strand windows in the top 1% (calibrated P ≤ 0.020876023786561414 for the paper's windows) |
| `best_window_id` | Window with the smallest calibrated P value (`chrom:start-end:strand`, 0-based start) |

**Selection and alignment**

| Column | Definition |
|---|---|
| `selection_route` | First route met, in this order: vertebrate_wide, mammal_conserved, primate_focused, high_score_rescue (selection strata, not lineage-specific origins) |
| `n_species_alignment` | Species in the final alignment (up to 55) |
| `n_sequences_alignment` | Sequences in the final alignment (paralogous loci included) |

**Structural evidence**

| Column | Definition |
|---|---|
| `icshape_measured` | Measurable in GSE145805 icSHAPE in at least one cell line (474 candidates) |
| `icshape_supported` | Empirical P (circularly shifted structure as control) ≤ 0.05 in at least half of the measured cell lines |
| `icshape_n_cell_lines` | Cell lines in which the core was measurable (≥ 50% of the core measured, ≥ 10 paired and ≥ 10 unpaired nucleotides) |
| `icshape_mean_auroc` | Mean over cell lines of the AUROC of icSHAPE reactivity for predicted unpaired versus paired nucleotides |
| `icshape_fraction_cell_lines_p_le_0.05` | Fraction of measured cell lines with empirical P ≤ 0.05 |
| `covariation_status` | Covariation under condition (iii) (high-confidence homologues aligned with MAFFT without structure): detected; not detected with expected ≥ 1 covarying pair; not detected with low power; not evaluable. Absence is not evidence against a structure |
| `covariation_iii_structure_free` | At least one proposed base pair shows significant covariation (R-scape, E < 0.05) under condition (iii), the primary condition (733 candidates) |
| `covariation_iii_two_pairs` | At least two proposed pairs are significant under condition (iii) |
| `covariation_iii_n_significant_pairs` | Number of significant proposed pairs under condition (iii) |
| `covariation_iii_n_pairs_tested` | Proposed pairs mapped onto the alignment and tested |
| `covariation_iii_expected_pairs` | Power: covarying pairs expected by R-scape |
| `covariation_iii_n_sequences` | Sequences in the condition (iii) alignment used by R-scape |
| `covariation_iii_mean_identity_pct` | Mean pairwise identity (%) of the condition (iii) alignment reported by R-scape |
| `covariation_i_cm_alignment` | Covariation detected under condition (i), the final alignment built with the covariance model (can be inflated by alignment to the structure) |
| `covariation_ii_same_sequences_mafft` | Covariation detected under condition (ii), the same sequences realigned with MAFFT |
| `structural_support` | `icshape_supported` or `covariation_iii_structure_free` (1,012 candidates) |
| `structural_evidence_measured` | icSHAPE was measurable, or covariation was evaluable with expected ≥ 1 covarying pair |

**Structural signal in homologues** (RLMHelix-MSA of the condition (iii) alignment against 19 SISSIz shuffles)

| Column | Definition |
|---|---|
| `homologue_msa_scored` | Scored with the human row removed and all 19 shuffles (14,565 candidates) |
| `homologue_rlmhelix_msa_no_human` | RLMHelix-MSA score with the human row removed |
| `homologue_rlmhelix_msa_no_human_z` | (score − mean of shuffles) / s.d. of shuffles, human row removed |
| `homologue_rlmhelix_msa_no_human_p` | Empirical P = (1 + #shuffles ≥ native) / 20, human row removed (0.05 is the floor) |
| `homologue_above_all_19_shuffles` | Scored above all 19 shuffles with the human row removed (5% expected by chance) |
| `homologue_rlmhelix_msa_with_human_z` | As `homologue_rlmhelix_msa_no_human_z`, with the human row kept |
| `homologue_above_all_19_with_human` | Scored above all 19 shuffles with the human row kept |

**Binding and annotation** (descriptive; not used for tiers)

| Column | Definition |
|---|---|
| `eclip_n_experiments` | ENCODE eCLIP experiments (of 250) with an IDR peak overlapping the core on the same strand |
| `eclip_experiments` | Those experiments as RBP (cell line), `;`-separated |
| `eclip_dsrbp` | Bound by one of the six dsRBPs (DGCR8, DROSHA, ILF3, STAU2, DHX30, XPO5) |
| `eclip_dsrbp_names` | The dsRBPs bound |
| `splice_site_distance_nt` | Distance to the nearest same-strand splice site in GENCODE v50 (0 = the core spans a splice site) |
| `splice_site_class` | `spans splice site`, `within 100 nt` or `farther` (`no same-strand splice site` when the chromosome strand has none) |
| `scan_region_types` | Region types of the source scan window (intron, lncRNA, UTRs) |
| `annotation_status` | Overlap with GENCODE v50 genes and transcripts: `same_strand_exonic`, else `same_strand_intronic`, `same_strand_gene_only`, `opposite_strand_only` or `no_gene_overlap` |
| `same_strand_genes` | Same-strand genes overlapping the core (`;`-separated) |
| `same_strand_gene_types` | Gene types of those genes |
| `same_strand_contexts` | Transcript contexts overlapped (CDS, 5UTR, 3UTR, UTR_unresolved, intron, exon_non_CDS_UTR) |
| `representative_gene` | Representative gene |
| `representative_gene_type` | Gene type of the representative gene |
| `representative_transcript` | Representative same-strand transcript: largest exonic overlap, then MANE Select, then largest transcript overlap, then smallest transcript ID (a display choice, not the expressed isoform) |
| `representative_context` | Context of the core in the representative transcript |
| `high_copy` | More than 100 high-confidence hits or final55 loci (copy-number flag; paralogues and pseudogenes may contribute) |
| `pseudogene_context` | The core overlaps a same-strand gene whose type contains `pseudogene` |
| `pseudogene_genes` | Those pseudogenes |
| `rfam_accessions` | Rfam 15.1 families with a significant hit overlapping the core on the same strand by at least 1 nt (primary chromosomes; 266 candidates) |
| `rfam_names` | Names of those Rfam families |

Tiers: A, 380 candidates; B, 4,631; C, 10,810. Absent covariation and missing icSHAPE measurements are not treated as
evidence against a candidate.

## Family table (`families.tsv`)

Sorted by best tier, then lowest lfdr.

| Column | Definition |
|---|---|
| `rlmfam_id` | RLM-Fam family ID (the `rlmfam_id` column of the candidate table) |
| `n_candidates` | Candidates in the family |
| `candidate_loci` | Loci of the candidates with strand (1-based inclusive; best tier first, then lowest lfdr; `;`-separated) |
| `representative_locus_hg38` | Locus of the representative candidate, the first of `candidate_loci` |
| `representative_strand` | Strand of the representative candidate |
| `genes` | Representative host genes of the candidates (`;`-separated, in the order of `candidate_loci`) |
| `region_contexts` | Regions of the representative transcripts overlapped by the cores (`;`-separated) |
| `best_tier` | Best evidence tier among the candidates |
| `min_lfdr` | Smallest lfdr among the candidates |
| `n_statistical_support` | Candidates with statistical support (BH window or lfdr ≤ 0.2) |
| `n_structural_support` | Candidates with structural support (icSHAPE or covariation in the structure-free alignment) |
| `n_overlapping_earlier_screens` | Candidates overlapping a prediction of the four earlier genome-wide screens (RNAz 2005, EvoFold v1 and v2, CMfinder CRSs); this overlap is not computed by this repository |
| `rfam` | Rfam families overlapped by the candidates (`;`-separated) |

## Regenerating the files

The public inputs are fetched with `scripts/download_data.py` (see `data/README.md`; `DATA` below is its destination
directory); the external tools are listed in `reproduce/README.md`. Arguments of each step are listed by
`rlmhelix <step> --help`, and the exact commands of the scan and the selection are in `docs/pipeline_scan.md` and
`docs/pipeline_select.md`.

```bash
rlmhelix scan prepare ...       # windows, repeat filters
rlmhelix scan score ...         # RLMHelix scores and calibrated P values (one GPU, about 2 days)
rlmhelix scan fdr ...           # BH q values, empirical null and lfdr -> scan/eligible_windows.parquet
                                #   (all columns; scan_windows.parquet of the Zenodo deposit will keep a subset)
rlmhelix select cores ...       # cores of the top 1% of windows
rlmhelix select chunk ...       # 10-kb chunks of the 55 genomes
rlmhelix select search ...      # Riboseek search in 20 vertebrates (three searches; docs/pipeline_select.md)
rlmhelix select routes ...      # four selection routes
rlmhelix select seed ...        # seed alignments and seed CMs (Infernal)
rlmhelix select expand ...      # expansion to 55 species -> select/expand/candidates.parquet,
                                #   candidates/<core_id>/final55.sto and final55.cm, homologues/<core_id>.fa
rlmhelix select homologues ...  # optional: rebuilds homologues/ (select expand already writes it)
rlmhelix select families ...    # provisional families -> select/families/families.tsv (membership only)

# candidate table of the catalogue steps: candidates.parquet with rlmfam_id and the family size of families.tsv
rlmhelix catalogue candidates select/expand/candidates.parquet --families select/families/families.tsv \
    -o candidates.tsv
I=DATA/icshape
rlmhelix catalogue icshape --candidates candidates.tsv --gtf $I/gencode26/gencode.v26.annotation.gtf.gz \
    --transcripts $I/gencode26/gencode.v26.transcripts.fa.gz \
    --track HEK293=$I/GSE145805/GSM4333256_293.out.txt.gz --track HeLa=$I/GSE145805/GSM4333258_HeLa.out.txt.gz \
    --track K562=$I/GSE145805/GSM4333260_K562.out.txt.gz --track HepG2=$I/GSE145805/GSM4333262_HepG2.out.txt.gz \
    --track H9=$I/GSE145805/GSM4333264_H9.out.txt.gz -o icshape.tsv
rlmhelix catalogue covariation --candidates candidates.tsv --homologues select/expand/homologues \
    --workdir rscape -o cov_iii.tsv
rlmhelix catalogue covariation --candidates candidates.tsv --condition ii --alignments select/expand/candidates \
    --workdir rscape -o cov_ii.tsv
rlmhelix catalogue covariation --candidates candidates.tsv --condition i --alignments select/expand/candidates \
    --workdir rscape -o cov_i.tsv
rlmhelix catalogue build --candidates candidates.tsv --windows scan/eligible_windows.parquet \
    --icshape icshape.tsv --covariation cov_iii.tsv cov_ii.tsv cov_i.tsv \
    --eclip Supplementary_Table_S8.xlsx --eclip-dir DATA/encode --gtf DATA/gencode50/gencode.v50.annotation.gtf.gz \
    --rfam DATA/rfam/rfam15.1_human_GRCh38_hits.tsv \
    -o rlmfam_candidates.tsv --families families.tsv --tier-summary tier_summary.tsv \
    --evidence-summary evidence_summary.tsv
# the homologue-signal columns need --homologue-msa TABLE, from a driver that is not included (see below)
```

**Candidate table.** `catalogue candidates` joins `candidates.parquet` and `families.tsv` on `query_id` and writes one
row per candidate with the working column names of the catalogue (`query_id` becomes `core_id`, `family_id`
`provisional_cluster_id` and `family_size` `cluster_size`; `rlmfam_id` is kept), sorted by `rlmfam_id` and `core_id`
(TSV, or parquet when the output name ends in `.parquet`). It stops when the table is empty or a candidate has no
family. Its columns (working names, in this order where present): `core_id`, `rlmfam_id`, `provisional_cluster_id`,
`cluster_size`, `chrom`, `strand`, `core_start0`, `core_end0`, `browser_locus`, `core_length`, `n_pairs`, `n_stems`,
`core_score`, `human_core_rna_sequence`, `human_core_predicted_ss`, `scan_pvalue`, `source_features`, `lineage_route`,
`msa_species`, `msa_sequences`, `high_copy`, `msa_path`, `cm_path`. `catalogue icshape` and `covariation` also accept
`candidates.parquet` directly (its column names are recognized); `build` needs the family columns of this table for
`rlmfam_id`, `family_size` and `--families`.

**Options.** `--eclip`, `--gtf`, `--rfam` and `--homologue-msa` are optional; without them the corresponding columns
are left empty.
- `--gtf` (GENCODE v50) fills the annotation columns (`annotation_status`, `same_strand_genes`,
  `same_strand_gene_types`, `same_strand_contexts`, `representative_gene`, `representative_gene_type`,
  `representative_transcript`, `representative_context`, `pseudogene_context`, `pseudogene_genes`), the splice-site
  columns (`splice_site_distance_nt`, `splice_site_class`) and the Families columns `genes` and `region_contexts`;
  it replaces annotation columns already in the candidate table and takes about a minute.
- `--eclip` takes Supplementary Table S8 as `.xlsx` (sheet Accessions; needs openpyxl, see
  `environments/README.md`), that sheet saved as TSV, or any table of experiments with `rbp` (or `target`), `cell` (or
  `cell_line`) and `file_accession` or `path`. When a `dataset` column is present only the rows `eCLIP peaks` (250
  experiments) are used. The IDR peak files `<file_accession>.bed.gz` are read from `--eclip-dir` (default: next to
  the table), for example `DATA/encode` written by `download_data.py --only encode`; the command stops when any is
  missing.
- `--rfam` takes hits with `chrom`, `start` (0-based), `end`, `strand`, `rfam_acc` and `rfam_id`, such as
  `rfam/rfam15.1_human_GRCh38_hits.tsv` written by `download_data.py` after the `rfam` group.
- `--homologue-msa` takes one row per candidate and human-row setting (`core_id`, `human_row` = `without`/`with`,
  `native`, `z`, `empirical_p`, `passes`, `n_valid_null`). The homologue-signal columns come from scoring each
  condition (iii) alignment and 19 SISSIz shuffles with `rlmhelix msa`, which needs SISSIz 0.1; the shuffling driver
  is not part of this repository.

**Covariation.** `catalogue covariation` needs MAFFT 7.526 and R-scape 2.6.16 (`--mafft`, `--rscape` give their
paths). For condition (iii), `--homologues` is a directory of `<core_id>.fa` with the human core, named by its
`core_id`, and its high-confidence homologues (`select/expand/homologues`, or the output of `select homologues`).
For conditions (i) and (ii), `--alignments` is a directory of `<core_id>/final55.sto` (`select/expand/candidates`) or
of `<core_id>.sto` (such as `alignments/` of the deposit). Candidates without an input file are left out and counted
on standard error, and the command stops when no candidate has one. Outputs go to `<workdir>/<condition>/<core_id>/`
(a relative `--workdir` works), and finished candidates are reused unless `--no-resume` is given.

**Windows.** The window table must hold all eligible windows: `scan/eligible_windows.parquet` of `rlmhelix scan fdr`,
or, once public, `scan_windows.parquet` of the deposit (it needs `chrom`, `start`, `end`, `strand` and the calibrated
P value as `p`, `p_value` or `pvalue`). Without an `lfdr` column, the lfdr is computed from all windows with the
paper's empirical null (`--null MU0 SIGMA0 PI0` gives another), and without a q value column the BH q values are
computed too. `--lfdr-curve lfdr_curve.tsv` also writes the lfdr curve of Supplementary Fig. S8a, b (`z`, `f`,
`pi0_f0`, `lfdr`); the lfdr is then recomputed from the P values even when the table has an `lfdr` column.
`n_top1pct_windows` counts windows at or below the top-1% cutoff of the window table (0.020876023786561414 for the
paper's 7,869,821 windows, printed on standard error); `--top1-p P` sets it, for example when the table is not the
full set of eligible windows.
